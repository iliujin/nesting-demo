## 产物与边界

真实求解截图：[桌面](screenshots/live-desktop.png)、[手机](screenshots/live-mobile.png)。

公开仓库不包含私有求解器源码、程序或凭证。本机 .env.local 被 Git 忽略，开发服务器的连接配置不会进入生产配置。

实际联调路径为本机浏览器 → 本机测试转发 → 私有 API → Worker → C++。这不等于 GitHub Pages 到公网 HTTPS 的验收；后者仍需要可用入口。

零间隙表示不额外留距，不保证容器没有空白或每对零件互相接触。坐标搜索网格分别为 strip=1、bin=0.01（输入坐标单位）。排样是通过校验的可行解，不承诺全局最优或全部历史基准均可求解。未验证高并发负载，首版一次执行一个任务。旧任务不会自动重算，需要重新提交。
