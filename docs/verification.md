## 边界

当前实际网络验收路径是本机浏览器 → 本机测试转发 → 私有 HTTP API → PostgreSQL/Worker → C++。这不等于 GitHub Pages 到公网 HTTPS 的验收；后者需要可用入口后另行完成。

在线演示有明确输入范围与数值边界，结果为可行解，不承诺全局最优或全部历史基准实例均可求解。未验证高并发负载；首版一次执行一个任务。关闭页面后不保留访客会话。
